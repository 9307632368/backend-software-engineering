# 01 — Fundamentals (2024 learning track)

The goal of this section is to understand how a backend responds to requests, checks data, stores information, and rejects unsafe requests. I kept it focused on backend programming rather than general Python lessons.

Start at [Tutorials](tutorials/README.md). The numbers show the recommended learning order. Every lesson has an `app.py`, a walkthrough, and sample HTTP requests. Tests live together in `/tests` at the repository root.

The **2024** label is a learning-track category only. It doesn't describe when commits were made.
