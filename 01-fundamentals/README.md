# 01 — Fundamentals (2024 Learning Track)

This section is about understanding how a backend works by **writing and running actual APIs**, not just reading definitions. It assumes basic Python familiarity, so it does not repeat the separate Python and DSA repositories.

- [Tutorials](tutorials/README.md): 8 short lessons on HTTP, validation, errors, CRUD, SQLite, dependency injection, pagination and API keys.
- [Practical examples](examples/README.md): 8 additional services on registration, file uploads, relational data, JWT, background jobs, Redis caching, logging and API tests.
- Exercises will be added as the next section; they are not included in this archive yet.

**Suggested order:** finish the tutorials, then try the example APIs and their `requests.http` files. Run `python -m pytest -q` from the repository root whenever you modify a service.

All contents belong to the 2024 portfolio collection. The year reflects the curriculum, not historical Git commit dates.
