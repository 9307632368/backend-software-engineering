# Reusable templates

- `fastapi-starter/` is a small **working** backend API scaffold.
- `project-readme-template.md` helps document a backend project accurately.
- `incident-postmortem-template.md` is for exercises, simulated incidents, or real incidents you actually experienced.
- `pull-request-template.md` helps reviewers understand changes.
- `api-design-checklist.md` helps plan an endpoint before coding.

To generate a project copy from `fastapi-starter/`, run `py tools\scaffold_project.py --dest .\sample-backend` from the 07-resources folder. The script will refuse to overwrite an existing destination.
