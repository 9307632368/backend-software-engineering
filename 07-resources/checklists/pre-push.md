# Before pushing to GitHub

- [ ] I can run this project from a clean folder.
- [ ] I used a fresh virtual environment and installed documented dependencies.
- [ ] Tests pass and results are not invented.
- [ ] README mentions implemented routes, not hypothetical features.
- [ ] No `.env` secrets, tokens, private datasets or real user details in Git.
- [ ] Generated files (`.venv`, `__pycache__`, `.db`, logs) are ignored.
- [ ] The project has clear credits if any code is adapted.
- [ ] Big media/model weights are linked or tracked appropriately, not accidentally committed.
- [ ] Git commit date reflects when I actually worked on this version.
